2. Top skills to learn (ranked by how many of the 16 jobs ask for them)

  1. Agent frameworks, especially LangGraph (Bosch GenAI, NIQ, Coinbase, Snowflake, HighRadius, GitLab). State graphs, tool calling, multi-agent handoff, memory (short and long term), human-in-the-loop. You already built routing and fallback by hand; LangGraph is the industry way to express it.
  2. Evals and observability (Snowflake, Bosch, NIQ, Coinbase, GitLab). Golden datasets, LLM-as-judge, regression tests for prompts, tracing with LangSmith or Langfuse, quality metrics (accuracy, faithfulness, safety). Snowflake's description calls this "first-class".
  3. Advanced SQL + statistics + a BI tool (Celonis AE, Stripe x2, Celonis Associate, Snowflake). Window functions, CTEs, reconciliation queries, hypothesis tests, simple forecasting, one of Power BI / Tableau / Looker.
  4. Solutions / pre-sales skills (Glean, ServiceNow, Celonis Associate, Sarvam, HighRadius FDE, Snowflake FDE). Discovery questions, story-driven demos, proofs of value, ROI/business cases, objection handling.
  5. Advanced RAG (Bosch GenAI, NIQ, Glean). Hybrid search (keyword + vectors), re-ranking, vector databases (FAISS, Chroma, Pinecone), Graph RAG, permission-aware retrieval.
  6. Shipping AI services (Bosch, Coinbase, NIQ). FastAPI, Docker, CI/CD (you have this from Conzura), one cloud AI platform: Azure OpenAI / AI Foundry is the best pick for Bosch and Indian enterprises.
  7. Protocols: MCP and A2A (Bosch GenAI, NIQ). Build one MCP server for a tool you own.
  8. Domain primers: Order-to-Cash and Accounts Receivable (HighRadius), process mining and PQL (Celonis), SaaS billing (Stripe), warehousing/transport (Bosch logistics), HR service delivery (ServiceNow), BFSI customer journeys (Sarvam).
  9. DSA + system design basics (HighRadius, Coinbase interviews). Dynamic programming (knapsack), graphs; "design an LLM support bot with human handoff".
